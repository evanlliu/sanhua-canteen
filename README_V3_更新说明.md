# sanhua-canteen V3 — 员工端语言下拉 + 后台登录免滚动

## 本版改动

1. 员工预约页右上角语言切换从“点击轮换”改为原生下拉选择框，包含「中文 / English / Español (México)」。
2. 语言变化仍会更新页面文字、餐次名称和预约信息；保留原来的浏览器语言偏好记忆。
3. 后台登录页改为更紧凑的居中登录卡片，去掉登录状态下的底部页脚，常见电脑与手机屏幕不再需要纵向滚动。
4. 登录成功后正常显示可以滚动的管理后台；退出登录返回不滚动的登录页。
5. 预约数据库、餐次动态配置、GitHub 接口、Token 混淆和 `config.js` 均不修改。

## GitHub 更新步骤

将 **V3_仅需替换的5个文件.zip** 解压得到的五个文件覆盖上传到 `sanhua-canteen` 仓库 `main` 分支根目录：

- `index.html`
- `staff.js`
- `styles.css`
- `admin.html`
- `admin.js`

**不要覆盖 `config.js`！** 你之前填写的 `tokenCiphertext`、`keyMaterial` 以及 `adminPassword: '1123'` 原样保留。

**`data` 分支无需修改。**

提交后等 GitHub Pages 部署完成，使用 Ctrl + F5 强制刷新页面，以清除浏览器缓存。
