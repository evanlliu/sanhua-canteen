# sanhua-canteen V8 后台标题布局优化

本版基于 V7（五小时 Cookie 后台登录版），只修改管理员登录后的页面布局：

- 删除原页面顶部独立的“退出登录”空栏。
- 将“食堂预约总览”改为“管理后台”。
- 删除“员工预约、花名册维护与自定义餐次设置，一处管理。”
- 同行显示标题、刷新数据和退出登录；在手机端标题与退出登录同一行，刷新控件自动换到下一行。
- 移除“OPERATIONS CENTER”副标题，减少无效顶部留白。

## 上传

将更新包内 `admin.html`、`styles.css` 上传到 GitHub `sanhua-canteen` 仓库 `main` 分支根目录，覆盖同名文件。
不需要覆盖 `config.js`，`data` 分支也无需任何操作。管理后台密码及已有预约数据不受影响。

完成 GitHub Pages 部署后 Ctrl+F5 强制刷新。
